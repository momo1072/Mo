Grundprinzip der Blockchain‑Datenstruktur
### 1️⃣ Visualisierung der Blockchain‑Struktur (Skizze)
**Merksatz**

Eine Blockchain ist eine kryptografisch verkettete Liste von Datenblöcken.
**Skizze (ASCII – leicht verständlich)**

```
┌────────────────────┐     ┌────────────────────┐     ┌────────────────────┐
│ Block 0 (Genesis)  │ →   │      Block 1       │ →   │     Block 2        │
│--------------------│     │--------------------│     │--------------------│
│ Prev. Hash: 0000   │     │ Prev. Hash: H0     │     │ Prev. Hash: H1     │
│ Payload: Daten     │     │ Payload: Daten     │     │ Payload: Daten     │
│ Current Hash: H0   │     │ Current Hash: H1   │     │ Current Hash: H2   │
└────────────────────┘     └────────────────────┘     └────────────────────┘
```

#### Erklärung zur Skizze

- Block 0 (Genesis‑Block)

   - Kein Vorgänger → Previous Hash = 0000


- Jeder Block enthält:

   - Payload (Nutzdaten, z. B. Transaktionen)
   - Previous Hash → kryptografischer Zeiger auf den vorherigen Block
   - Current Hash → eigener Hash aus Payload + Previous Hash

- Verkettung erfolgt nicht über Speicheradressen, sondern über Hash‑Werte

**Hash‑Berechnung (Kernprinzip)**

──────>  Current Hash = SHA256(Payload + Previous Hash)

---


### 2️⃣ Erklärung der Manipulationssicherheit (Dominoeffekt)
**Kurzfassung für den IT‑Blog**
Eine Blockchain ist manipulationssicher, weil jede Änderung an einem Block sofort alle nachfolgenden Blöcke ungültig macht.
**Technische Erklärung (prägnant)**
Angenommen, die Payload in Block 1 wird nachträglich verändert:

1. ❌ Die Payload ändert sich
2. ❌ Der **Current Hash von Block 1** ändert sich automatisch
3. ❌ Der **Previous Hash von Block 2** passt nicht mehr
4. ❌ Block 2 erhält einen falschen Hash
5. ❌ Dieser Fehler setzt sich **bis zum letzten Block fort**

**➡ Die gesamte Kette verliert ihre Integrität**
**Merksatz (prüfungsreif)**

Eine einzelne Datenmanipulation zerstört wegen der Hash‑Verkettung die Integrität aller folgenden Blöcke.

---


#### 3️⃣ Reflexion: Abgrenzung zur doppelt verketteten Liste
**Vergleich in 2–3 Sätzen (IHK‑tauglich)**
Eine klassische doppelt verkettete Liste verwendet einfache Speicheradressen als Zeiger, die leicht manipuliert werden können.
Die Blockchain nutzt hingegen **kryptografische Hash‑Werte**, die direkt vom Inhalt des vorherigen Blocks abhängen.
**Jede Manipulation ist sofort erkennbar**, da sie die gesamte nachfolgende Struktur ungültig macht.

#### Kurz‑Merksatz
**Hash‑Zeiger sichern Inhalte – Speicherzeiger nicht.**
