# Blade-Systeme
**Server-Architekturen**

---

## Überblick & Aufbau

| Begriff | Beschreibung |
|---|---|
| **Enclosure** | Chassis nimmt mehrere Blades auf |
| **Shared Resources** | Stromversorgung, Kühlung, Netzwerk |
| **Hot-Swap** | Blades im Betrieb austauschbar |
| **Skalierbar** | Einfache Kapazitätserweiterung |

### Blade Chassis / Enclosure

```
┌─────────────────────────────────────────┐
│           Blade Chassis / Enclosure     │
│  ┌──────────────┐  ┌──────────────┐     │
│  │  Blade 1     │  │  Blade 2     │     │
│  │ (Web Server) │  │ (DB Server)  │     │
│  └──────────────┘  └──────────────┘     │
│  ┌──────────────┐  ┌──────────────┐     │
│  │  Blade 3     │  │  Blade 4     │     │
│  │ (App Server) │  │  (Backup)    │     │
│  └──────────────┘  └──────────────┘     │
│  ┌──────────────┐  ┌──────────────┐     │
│  │  Blade 5     │  │  Blade 6     │     │
│  │  (VM Host)   │  │   (Spare)    │     │
│  └──────────────┘  └──────────────┘     │
│  Midplane | Shared Power | Network      │
│  Fabric | Management                    │
└─────────────────────────────────────────┘
```
