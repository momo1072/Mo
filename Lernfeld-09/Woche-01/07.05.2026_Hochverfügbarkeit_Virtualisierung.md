### Hochverfügbarkeit und Virtualisierung

#### Das Problem: Single Point of Failure
Wenn eine Anwendung auf einem einzigen physischen Server läuft, ist das aus zwei Gründen problematisch: Zum einen ist es ineffizient, weil die Ressourcen des Servers selten vollständig ausgenutzt werden. Zum anderen entsteht ein sogenannter Single Point of Failure – fällt dieser eine Server aus, ist die gesamte Anwendung nicht mehr erreichbar. In professionellen IT-Umgebungen muss genau das vermieden werden, denn IT-Dienste sollen jederzeit verfügbar sein.

```
        ┌─────────────┐
        │   Nutzer    │
        └──────┬──────┘
               │
        ┌──────▼──────┐
        │  Anwendung  │
        └──────┬──────┘
               │
  ┌────────────▼────────────┐
  │  ⚠ SINGLE SERVER ⚠     │   ← Single Point of Failure
  │    (einziger Server)    │
  └────────────┬────────────┘
               │
         Server fällt aus
               │
        ┌──────▼──────┐
        │  ✗ AUSFALL  │  → Anwendung nicht mehr erreichbar
        └─────────────┘
```
---

#### Die Lösung: Virtualisierung
Virtualisierung löst dieses Problem mithilfe eines Hypervisors – einer Software, die zwischen der physischen Hardware und dem Betriebssystem sitzt. Der Hypervisor trennt diese beiden Schichten voneinander und schafft so eine Abstraktionsebene.
Dadurch wird es möglich, mehrere virtuelle Maschinen (VMs) gleichzeitig auf einem einzigen physischen Server zu betreiben. Jede VM verhält sich dabei wie ein eigenständiger Computer mit eigenem Betriebssystem und eigenen Anwendungen – obwohl sie sich die Hardware mit anderen VMs teilt.

```
  ┌─────────────────────────────────────────────────┐
  │              Physischer Server                  │
  │                                                 │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐      │
  │  │   VM 1   │  │   VM 2   │  │   VM 3   │      │
  │  │  OS + App│  │  OS + App│  │  OS + App│      │
  │  └────┬─────┘  └────┬─────┘  └────┬─────┘      │
  │       │             │             │             │
  │  ─────┴─────────────┴─────────────┴──────────   │
  │              H Y P E R V I S O R               │
  │  ─────────────────────────────────────────────  │
  │         Hardware (CPU · RAM · Speicher)         │
  └─────────────────────────────────────────────────┘
```
---

#### Vorteile für die Hochverfügbarkeit
Ein entscheidender Vorteil dieser Technik ist die erhöhte Ausfallsicherheit: Wenn ein physischer Server ausfällt, kann eine VM schnell auf einem anderen Host (also einem anderen physischen Server) neu gestartet werden. Die Anwendung ist dadurch nur kurz oder gar nicht unterbrochen, was die Verfügbarkeit deutlich erhöht.

```
  ┌─────────────────────┐          ┌─────────────────────┐
  │      Host A         │          │      Host B         │
  │  ┌───┐ ┌───┐ ┌───┐  │          │  ┌───┐ ┌───┐ ┌───┐  │
  │  │VM1│ │VM2│ │VM3│  │          │  │VM4│ │VM5│ │VM6│  │
  │  └───┘ └───┘ └───┘  │          │  └───┘ └───┘ └───┘  │
  │    Hypervisor        │          │    Hypervisor        │
  └──────────┬──────────┘          └──────────▲──────────┘
             │                                │
             │   Host A fällt aus!            │
             │   VM2 wird migriert ──────────►│
             ▼                                │
           ✗ Ausfall                   VM2 läuft weiter
```
---

#### Blade-Systeme als Ergänzung
Um solche virtualisierten Umgebungen effizient zu betreiben, werden häufig Blade-Systeme eingesetzt. Dabei handelt es sich um besonders kompakte Server-Module, die platzsparend in ein gemeinsames Gehäuse (das sogenannte Blade-Chassis) eingeschoben werden. Sie teilen sich Stromversorgung, Kühlung und Netzwerkverbindungen, was die Infrastruktur effizienter und übersichtlicher macht.

```
  ╔══════════════════════════════════════════════════════╗
  ║                  Blade-Chassis                       ║
  ║  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐        ║
  ║  │Blade 1 │ │Blade 2 │ │Blade 3 │ │Blade 4 │  ...   ║
  ║  │(Server)│ │(Server)│ │(Server)│ │(Server)│        ║
  ║  └────────┘ └────────┘ └────────┘ └────────┘        ║
  ║  ─────────────────────────────────────────────────  ║
  ║       Gemeinsame Stromversorgung & Kühlung           ║
  ║       Gemeinsame Netzwerkverbindung (Switch)         ║
  ╚══════════════════════════════════════════════════════╝
         │              │              │
    Kompakt        Energieeffizient   Skalierbar
```
---

#### Zusammenfassung
Hochverfügbarkeit ist ein zentrales Ziel moderner IT-Infrastrukturen. Virtualisierung – ermöglicht durch den Hypervisor – ist dabei ein wichtiges Werkzeug: Sie erhöht die Effizienz, reduziert Ausfallrisiken und ermöglicht eine flexible, schnell reagierende Serverumgebung. Blade-Systeme ergänzen dies durch eine platzsparende und gut skalierbare Hardware-Basis.
