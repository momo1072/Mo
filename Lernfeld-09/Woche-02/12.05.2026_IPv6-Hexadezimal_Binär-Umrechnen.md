## 1. Grundprinzip

Bei IPv6 arbeitest du mit **Hexadezimalzahlen**.
Für Binärdarstellung gilt eine einfache Regel:

```
1 Hex-Ziffer  =  4 Bit
4 Hex-Ziffern =  16 Bit  =  1 IPv6-Gruppe
8 Gruppen     =  128 Bit =  vollständige IPv6-Adresse
32 Hex-Ziffern × 4 Bit   =  128 Bit  ✔ (Probe)
```

**Warum genau 4 Bit pro Hex-Ziffer?**

```
Hex geht von 0 bis F  →  16 mögliche Werte
Binär mit 4 Bit:  2⁴  =  16 mögliche Werte  ✔

→ Perfekte Übereinstimmung: 1 Hex = 4 Bit, immer!
```

> 📌 **Merksatz:** Jede Hex-Ziffer = genau **4 Bit**.
> Einfach jede Ziffer einzeln umrechnen und zusammensetzen.

## 2. Die Hex-Tabelle

Lerne diese Tabelle – sie ist die Grundlage für alle Umrechnungen:

```
Hex   Dezimal   Binär      Stellenwerte (8-4-2-1)
──────────────────────────────────────────────────
 0       0      0000       0+0+0+0
 1       1      0001       0+0+0+1
 2       2      0010       0+0+2+0
 3       3      0011       0+0+2+1
 4       4      0100       0+4+0+0
 5       5      0101       0+4+0+1
 6       6      0110       0+4+2+0
 7       7      0111       0+4+2+1
 8       8      1000       8+0+0+0
 9       9      1001       8+0+0+1
 A      10      1010       8+0+2+0
 B      11      1011       8+0+2+1
 C      12      1100       8+4+0+0
 D      13      1101       8+4+0+1
 E      14      1110       8+4+2+0
 F      15      1111       8+4+2+1
──────────────────────────────────────────────────
```

**Eselsbrücken:**

```
0 = 0000  →  alle aus
F = 1111  →  alle an
8 = 1000  →  nur die Große (8er) an
1 = 0001  →  nur die Kleine (1er) an
A = 1010  →  8+2 = 10 → abwechselnd: 1-0-1-0
C = 1100  →  8+4 = 12 → zwei an, zwei aus
```

## 3. Schritt-für-Schritt Erklärung

### Wie rechnet man eine Hex-Ziffer in Binär um?

Jede Stelle hat einen festen Wert: **8 – 4 – 2 – 1** (von links nach rechts).

```
Stelle:   8   4   2   1
Bit:      ?   ?   ?   ?
```

**Frage bei jeder Stelle:** Passt dieser Wert noch rein?

```
Beispiel: Hex-Ziffer  D  =  Dezimal 13

Stelle 8:  13 ≥ 8?  JA  → Bit = 1,  Rest: 13 − 8 = 5
Stelle 4:   5 ≥ 4?  JA  → Bit = 1,  Rest:  5 − 4 = 1
Stelle 2:   1 ≥ 2?  NEIN → Bit = 0,  Rest:  1
Stelle 1:   1 ≥ 1?  JA  → Bit = 1,  Rest:  0

Ergebnis:   1  1  0  1  =  1101
```

**Alle Buchstaben systematisch:**

```
Ziffer   Dezimal   8?   4?   2?   1?   Binär
──────────────────────────────────────────────
  A        10      JA  NEIN  JA  NEIN  1010
  B        11      JA  NEIN  JA   JA   1011
  C        12      JA   JA  NEIN NEIN  1100
  D        13      JA   JA  NEIN  JA   1101
  E        14      JA   JA   JA  NEIN  1110
  F        15      JA   JA   JA   JA   1111
```

## 4. Hex → Binär: Vollständiges Beispiel

**Adresse:** `2001:0db8:0000:0000:0000:0000:0002:0001`

Jede Gruppe wird Ziffer für Ziffer umgerechnet:

```
┌──────────┬────────┬──────────────────────────────────────┐
│ Gruppe   │  Hex   │  Binär (je 4 Bit pro Ziffer)         │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 1 │  2001  │  2=0010  0=0000  0=0000  1=0001      │
│          │        │  0010 0000 0000 0001                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 2 │  0db8  │  0=0000  d=1101  b=1011  8=1000      │
│          │        │  0000 1101 1011 1000                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 3 │  0000  │  0=0000  0=0000  0=0000  0=0000      │
│          │        │  0000 0000 0000 0000                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 4 │  0000  │  0000 0000 0000 0000                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 5 │  0000  │  0000 0000 0000 0000                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 6 │  0000  │  0000 0000 0000 0000                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 7 │  0002  │  0=0000  0=0000  0=0000  2=0010      │
│          │        │  0000 0000 0000 0010                  │
├──────────┼────────┼──────────────────────────────────────┤
│ Gruppe 8 │  0001  │  0=0000  0=0000  0=0000  1=0001      │
│          │        │  0000 0000 0000 0001                  │
└──────────┴────────┴──────────────────────────────────────┘
```

**Vollständiges Ergebnis (128 Bit):**

```
Gr.1:  0010 0000 0000 0001
Gr.2:  0000 1101 1011 1000
Gr.3:  0000 0000 0000 0000
Gr.4:  0000 0000 0000 0000
Gr.5:  0000 0000 0000 0000
Gr.6:  0000 0000 0000 0000
Gr.7:  0000 0000 0000 0010
Gr.8:  0000 0000 0000 0001
```

**Probe:** 8 Gruppen × 16 Bit = **128 Bit** ✔

## 5. Binär → Hex: Der Rückweg

Immer **4 Bit** zusammenfassen → ergibt eine Hex-Ziffer:

```
Binär:    1111 1110 1000 0000
          └──┘ └──┘ └──┘ └──┘
           F    E    8    0
Hex:      FE80
```

**Weiteres Beispiel – Interface ID:**

```
Binär:   1010 1000  1011 1011  1100 1100  1111 1111
         └──┘ └──┘  └──┘ └──┘  └──┘ └──┘  └──┘ └──┘
          A    8     B    B     C    C     F    F
Hex:     A8BB:CCFF
```

**Beispiel mit Buchstaben und Zahlen gemischt:**

```
Binär:   0010 0000  0000 0001  0000 1101  1011 1000
         └──┘ └──┘  └──┘ └──┘  └──┘ └──┘  └──┘ └──┘
          2    0     0    1     0    D     B    8
Hex:     2001:0DB8
```

> 📌 **Merksatz Rückweg:** Immer 4 Bit von links zusammenfassen.
> Nie 3 oder 5 Bit – immer genau 4!

## 6. Praxisbeispiel: Link-Local-Adresse

**Adresse:** `fe80::1`
**Vollständig:** `fe80:0000:0000:0000:0000:0000:0000:0001`

```
Gruppe 1 – fe80:
  f = 1111
  e = 1110
  8 = 1000
  0 = 0000
  → 1111 1110 1000 0000

Gruppen 2–7 – 0000 (je 6 ×):
  → 0000 0000 0000 0000  (× 6)

Gruppe 8 – 0001:
  0 = 0000
  0 = 0000
  0 = 0000
  1 = 0001
  → 0000 0000 0000 0001
```

**Vollständig in Binär:**

```
1111111010000000 : 0000000000000000 : 0000000000000000 : 0000000000000000
0000000000000000 : 0000000000000000 : 0000000000000000 : 0000000000000001
```

> 📌 **Erkenntnis:** `FE80` = `1111 1110 1000 0000`
> Die ersten 10 Bit sind `1111111010` → das ist immer eine **Link-Local-Adresse!**
> Daran erkennst du sie auch direkt im Binärformat.

## 7. Übungsaufgaben: IPv6 Kurzform → Vollständig ausschreiben

**Aufgabe:** Schreibe die vollständige IPv6-Adresse aus (alle 8 Gruppen, je 4 Hex-Ziffern).

```
1.  2001:db8::28:b
2.  2001:db8::1
3.  fe80::acca:2:b:333:897b
4.  fe80::acca:2:b
5.  fe80:acca:2::b
6.  fe80:0:acca:2::b
7.  fe80::acca:2:b:11:55
```

**Lösungen:**

```
Vorgehensweise:
  1. Gruppen links und rechts von :: zählen
  2. Fehlende Gruppen = 8 − gezählte Gruppen
  3. :: durch entsprechend viele 0000 ersetzen
  4. Alle Gruppen auf 4 Stellen mit führenden Nullen auffüllen

──────────────────────────────────────────────────────────────────────
1.  2001:db8::28:b
    Links: 2001, db8 = 2 | Rechts: 28, b = 2 | Fehlend: 8−4 = 4
    → 2001:0db8:0000:0000:0000:0000:0028:000b

2.  2001:db8::1
    Links: 2001, db8 = 2 | Rechts: 1 = 1 | Fehlend: 8−3 = 5
    → 2001:0db8:0000:0000:0000:0000:0000:0001

3.  fe80::acca:2:b:333:897b
    Links: fe80 = 1 | Rechts: acca,2,b,333,897b = 5 | Fehlend: 8−6 = 2
    → fe80:0000:0000:acca:0002:000b:0333:897b

4.  fe80::acca:2:b
    Links: fe80 = 1 | Rechts: acca,2,b = 3 | Fehlend: 8−4 = 4
    → fe80:0000:0000:0000:0000:acca:0002:000b

5.  fe80:acca:2::b
    Links: fe80,acca,2 = 3 | Rechts: b = 1 | Fehlend: 8−4 = 4
    → fe80:acca:0002:0000:0000:0000:0000:000b

6.  fe80:0:acca:2::b
    Links: fe80,0,acca,2 = 4 | Rechts: b = 1 | Fehlend: 8−5 = 3
    → fe80:0000:acca:0002:0000:0000:0000:000b

7.  fe80::acca:2:b:11:55
    Links: fe80 = 1 | Rechts: acca,2,b,11,55 = 5 | Fehlend: 8−6 = 2
    → fe80:0000:0000:acca:0002:000b:0011:0055
```

## 8. Übungsaufgaben: Vollständig → Kurzform

**Aufgabe:** Kürze die folgenden IPv6-Adressen so weit wie möglich.

```
1.  2001:0db8:0000:0001:0001:0001:0001:0001
2.  af00:0000:0000:e255:0000:0001:332d:81fa
3.  beaf:0776:00a0:e222:d000:0012:0000:0000
4.  fd00:0000:0000:0000:0000:0000:0000:000b
5.  2001:0db8:0000:0000:0000:0000:0002:0001
6.  a21b:c756:0000:0000:1234:0000:0000:01ab
7.  2001:0bb8:0000:0000:0000:0000:1428:0057
```

**Lösungen:**

```
Vorgehensweise:
  Schritt 1: Führende Nullen jeder Gruppe weglassen
  Schritt 2: Längste Null-Folge → :: setzen
             (bei Gleichstand: die ERSTE Folge)
  Schritt 3: :: nur EINMAL verwenden!

──────────────────────────────────────────────────────────────────────
1.  2001:0db8:0000:0001:0001:0001:0001:0001
    Nach Schritt 1:  2001:db8:0:1:1:1:1:1
    Null-Folgen:     nur Gruppe 3 (einzeln) → kein ::
    → 2001:db8:0:1:1:1:1:1

2.  af00:0000:0000:e255:0000:0001:332d:81fa
    Nach Schritt 1:  af00:0:0:e255:0:1:332d:81fa
    Null-Folgen:     Gr.2–3 = 2 Gruppen | Gr.5 = 1 Gruppe
    Längste: Gr.2–3 → ::
    → af00::e255:0:1:332d:81fa

3.  beaf:0776:00a0:e222:d000:0012:0000:0000
    Nach Schritt 1:  beaf:776:a0:e222:d000:12:0:0
    Null-Folgen:     Gr.7–8 = 2 Gruppen → :: ans Ende
    → beaf:776:a0:e222:d000:12::

4.  fd00:0000:0000:0000:0000:0000:0000:000b
    Nach Schritt 1:  fd00:0:0:0:0:0:0:b
    Null-Folgen:     Gr.2–7 = 6 Gruppen → größte mögliche Kürzung
    → fd00::b

5.  2001:0db8:0000:0000:0000:0000:0002:0001
    Nach Schritt 1:  2001:db8:0:0:0:0:2:1
    Null-Folgen:     Gr.3–6 = 4 Gruppen → ::
    → 2001:db8::2:1

6.  a21b:c756:0000:0000:1234:0000:0000:01ab
    Nach Schritt 1:  a21b:c756:0:0:1234:0:0:1ab
    Null-Folgen:     Gr.3–4 = 2 Gruppen | Gr.6–7 = 2 Gruppen
    ⚠ GLEICH LANG → ERSTE Folge wird ::, zweite bleibt als 0:0
    → a21b:c756::1234:0:0:1ab

7.  2001:0bb8:0000:0000:0000:0000:1428:0057
    Nach Schritt 1:  2001:bb8:0:0:0:0:1428:57
    Null-Folgen:     Gr.3–6 = 4 Gruppen → ::
    → 2001:bb8::1428:57
```

## 10. Merksätze & Schnellreferenz

### Merksätze

> **M1 – Grundregel:**
> 1 Hex-Ziffer = genau 4 Bit. Nie mehr, nie weniger.
> 32 Hex-Ziffern × 4 Bit = 128 Bit = eine IPv6-Adresse.

> **M2 – Stellenwerte:**
> 8 – 4 – 2 – 1 (von links nach rechts).
> Gesetzte Bits addieren → ergibt den Dezimalwert.

> **M3 – Hex → Binär:**
> Jede Ziffer einzeln umrechnen. Ergebnis zusammensetzen.
> Immer mit führenden Nullen auf 4 Bit auffüllen!

> **M4 – Binär → Hex:**
> Immer genau 4 Bit von links zusammenfassen → eine Hex-Ziffer.

> **M5 – Kurzschreibweise:**
> Führende Nullen weglassen → :: für längste Null-Folge.
> :: nur einmal! Bei Gleichstand: erste Folge kürzen.

> **M6 – Ausschreiben:**
> Gruppen links + rechts von :: zählen.
> 8 − gezählte Gruppen = Anzahl der 0000-Gruppen für ::.

> **M7 – Link-Local erkennen:**
> FE80 = 1111 1110 1000 0000.
> Erste 10 Bit = 1111111010 → immer Link-Local-Adresse!

### Wichtige Adressen in Binär

```
FE80  =  1111 1110 1000 0000  →  Link-Local Präfix
FF02  =  1111 1111 0000 0010  →  Multicast
0000  =  0000 0000 0000 0000  →  Nullgruppe
FFFF  =  1111 1111 1111 1111  →  alle Bits gesetzt
```

### Rechenweg auf einen Blick

```
Hex → Binär:
  1. Jede Hex-Ziffer einzeln nehmen
  2. Stellenwerte 8-4-2-1 anlegen
  3. Bits setzen (1) oder löschen (0)
  4. Ergebnis: immer 4 Bit pro Ziffer

Binär → Hex:
  1. Bits in 4er-Gruppen aufteilen (von links)
  2. Jeden 4er-Block mit 8-4-2-1 auswerten
  3. Ergebnis: eine Hex-Ziffer pro Block

Probe:
  8 Gruppen × 4 Hex-Ziffern × 4 Bit = 128 Bit ✔
```
